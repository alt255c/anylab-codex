# Оформление ЛР5

lab-5.xml содержит обезличенные элементы оформления из предоставленного ALP. Их применяет restore_tabbed_views, а сценарий вызывает её после настройки модели.

Исходная камера: X=50, Y=350, Z=200; RotationX=35, RotationZ=-45. Frame: 1000×600. Размер окна 3D: 1000×550, FollowCamera=false. Эти параметры задают исходный ракурс и штатную навигацию, а не общий вид всей расширенной линии.

Для общего обзора создаётся отдельная демонстрационная копия или видеоплан. Стартовый вид, вкладки и camera в итоговом ALP при этом сохраняются.

Для видео с движением камеры используется `video --tour`: исходная ALP не изменяется, отдельная копия автоматически переключает 2D → 3D и проводит камеру вдоль участков до общего вида. Маршрут камеры задаётся в record_tour отдельно для средней и полной линии. Углы ALP хранятся в градусах, в Camera3D Java API передаются радианы.

В режиме tour ракурс 35°/−45° сохраняется на всех позициях. Проход содержит остановки по 3 секунды, плавные переходы по 1.5 секунды и завершающий общий план. В Forklift сохраняется sittingWorker: водители входят в обе визуализации.
