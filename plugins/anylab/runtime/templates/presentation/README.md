# Оформление ЛР5

lab-5.xml содержит обезличенные элементы оформления из предоставленного ALP. Их применяет restore_tabbed_views, а сценарий вызывает её после настройки модели.

Исходная камера: X=50, Y=350, Z=200; RotationX=35, RotationZ=-45. Frame: 1000×600. Размер окна 3D: 1000×550, FollowCamera=false. Эти параметры задают исходный ракурс и штатную навигацию, а не общий вид всей расширенной линии.

Для общего обзора создаётся отдельная демонстрационная копия или видеоплан. Стартовый вид, вкладки и camera в итоговом ALP при этом сохраняются.
