# ЛР5, задание 5.2: полный конвейер

Обезличенный самостоятельный шаблон. Использует среднюю часть из задания 5.1, загрузочный участок с боковой подачей компонента и соединением с поддоном и листом, затем разгрузку и три раздельных склада. В модели есть склады для хрупких, ручных и обычных коробок и общий пул из трёх погрузчиков.

При доработке сверяйте загрузочную часть с открытым примером ConveyorEnter, а отвод коробок и разгрузку — с ConveyorExit. Сохраняйте порядок сборки: поддон и лист, затем компонент, затем упаковка. Проверьте, что все три класса коробок попадают в свой склад, а погрузчики возвращаются в доступную позицию. Основные объекты и ресурсы: `partSource`, `partFeeder`, `fitSheet`, `fitPart`, `fragileWarehouse`, `manualWarehouse`, `ordinaryWarehouse`, `forklift`.

Параметры запуска и блоков приведены в `Model.fill.json`. Для выбранного варианта меняйте интенсивность поступления согласно постановке и повторно собирайте/запускайте модель. Все файлы `3d/` являются зависимостями проекта.
