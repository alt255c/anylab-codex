# ЛР5, задание 5.2: полный конвейер

Обезличенный самостоятельный шаблон. Использует среднюю часть из задания 5.1, загрузочный участок с боковой подачей компонента и соединением с поддоном и листом, затем разгрузку и три раздельных склада. В модели есть склады для хрупких, ручных и обычных коробок и общий пул из трёх погрузчиков.

При доработке сверяйте загрузочную часть с открытым примером ConveyorEnter, а отвод коробок и разгрузку — с ConveyorExit. Сохраняйте порядок сборки: поддон и лист, затем компонент, затем упаковка. Проверьте, что все три класса коробок попадают в свой склад, а погрузчики возвращаются в доступную позицию. Основные объекты и ресурсы: `partSource`, `partFeeder`, `fitSheet`, `fitPart`, `fragileWarehouse`, `manualWarehouse`, `ordinaryWarehouse`, `forklift`.

Параметры запуска и блоков приведены в `Model.fill.json`. Для общего задания ЛР5 меняйте интенсивность поступления и оформление согласно пожеланиям пользователя и повторно собирайте/запускайте модель. Все файлы `3d/` являются зависимостями проекта.

Рядом с ALP должен лежать один файл «Демонстрация.mp4» с последовательностью 2D → 3D. В 2D сохраняются стандартные люди и погрузчики с водителями. Коробки различаются материалами: обычные — бирюзовые, хрупкие — оранжевые, ручные — синие. Плоскости с эмблемой над коробкой не используются.

Для воспроизводимой видеодемонстрации: `video --tour` создаёт отдельную копию этой модели и один MP4 с последовательностью 2D → непрерывное движение камеры 3D → общий вид. Камера исходного ALP остаётся по образцу. Результат сохранять рядом с ALP как «Демонстрация.mp4».

При видеопроходе с отдалением до общего вида увеличивай FarClippingDistance в демонстрационной копии до 10000, иначе часть складов/линии обрезается. Погрузчики и sittingWorker сохраняются в исходной модели и копии для записи.

Проверка подачи: partStart.Offset=0; partJoin.Offset=180 при длине боковой ленты 205. Смещение 180 соответствует пересечению лент, оставшиеся 25 — геометрический запас до дальнего края. loadingTravel ведёт поддон от нулевого смещения к assemblyJoin.Offset=82; loadingGate разрешает следующий поддон после освобождения предыдущим входного участка. До сборки не отображать коробку.
