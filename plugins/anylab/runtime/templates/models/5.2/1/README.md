# ЛР5, задание 5.2

Самостоятельный обезличенный ALP. Используйте conveyor_scenario для интенсивности, зерна и оформления; сохраняйте ресурсы 3d рядом с проектом.

Сначала по ленте движется поддон с плоской заготовкой. По поперечной ленте подаётся втулка; fitPart присоединяет её к комплекту. У foldingWorker заготовка останавливается в foldBox на 4 секунды, затем boxFormed включает стенки открытой коробки. afterAssembly продолжает движение. Упаковочная станция закрывает коробку и наносит полосу ленты. Ручные синие коробки уже собраны, создаются только кнопкой и проходят свою подающую ленту. Корпуса категорий имеют отдельные постоянные цвета.

Загрузка перенесена из установленного ConveyorEnter: source → palletStockBuffer → loadingGate → liftUp (7 с) → conveyorEnter → fitSheet → loadingTravel. Листы проходят sheetSource → sheetBuffer → putSheetOnPallet (8 с) → fitSheet.in2. Реальные пути и узлы входят в loadingNetwork. Точка palletEntry принадлежит loadingBelt; после неё Convey продолжает движение с текущего положения. Прежнего fitPallet и фиктивного пополнения постоянного запаса нет. Разгрузка использует три погрузчика с сидящими водителями и три склада.

Контроль: foldedBoxes ≤ assembled, unsealedOutput=0, invalidOutput=0; проверяйте достигнутый горизонт, ручную подачу и обе упаковочные ветви. В проекте есть Simulation и настоящий Capacity (4–28 коробок/мин, шаг 4, по 900 с). Измерения после смены загрузочной схемы выполняются заново.

Видеодемонстрация: один MP4 рядом с ALP, сначала 2D, затем плавный проход 3D с остановками у загрузки, работника, упаковки и выхода. Камеру и вкладки исходной модели сохраняйте. Запись выполняйте в отдельной копии. Проверяйте превращение листа в коробку, видимость втулки и закрытие крышки по готовому MP4.

Загрузку выполняют два работника: поддон ожидает у palletBuffer, лист — на столе у palletSheetBuffer. Delay хранит груз в этих узлах, а не перемещает его по воздуху вдоль palletLiftPath/sheetLoadPath. Длительности 7/8 секунд и ConveyorEnter/Combine сохранены.
