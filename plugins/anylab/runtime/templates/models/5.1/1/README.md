# ЛР5, задание 5.1

Для воспроизводимой видеодемонстрации: `video --tour` создаёт отдельную копию этой модели и один MP4 с последовательностью 2D → непрерывное движение камеры 3D → общий вид. Камера исходного ALP остаётся по образцу. Результат сохранять рядом с ALP как «Демонстрация.mp4».

Подача и упаковка используют явные роли cargoRole (поддон/деталь/лист/собранная коробка). Стандартные фигуры обеспечивают независимые цвета и открытое/закрытое состояние; парящие знаки и общие меши коробок не используются. Точки учитывают передний край: partJoin.Offset=185 и assemblyJoin.Offset=102. Поддон остаётся на ленте при сборке; SOURCE_CURRENT_POSITION продолжает движение. Проверяйте unsealedOutput=0 и invalidOutput=0, а также счётчики упаковки каждого типа.
