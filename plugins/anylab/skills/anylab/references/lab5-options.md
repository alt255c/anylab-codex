# Настройки моделей, записи и комплекта ЛР5

Для 5.1 и 5.2 сначала согласуйте две идеи внешнего вида. Опции каждого вызова
`conveyor_scenario` независимы. Укажите `full_line: true` для 5.2 и начните с
соответствующего шаблона. Поддерживаются `compact_straight`, `extended_offset`
и `smooth_s`. Детали: `blue_sleeve`, `orange_sleeve`, `silver_spool` или
`brick`, `coffee` (стаканчик с крышкой) или `cat` (фигурка котика). Дополнительные цвета, прямой вход и декор передаются в `scene`.

```json
{
  "theme": "retro_factory",
  "colors": {"ordinary": "#C59444", "fragile": "#842E42", "manual": "#203A65", "sheet": "#D9B785"},
  "label": "Workshop",
  "label_color": "#B92129",
  "label_angle": 41,
  "inlet": "straight",
  "wall": "outside",
  "sign": "КИРПИЧНЫЙ ЦЕХ"
}
```

Темы: `classic`, `retro_factory`, `smart_factory`, `sci_fi`. Допустимые
ключи `colors`: `ordinary`, `fragile`, `manual`, `tape`, `sheet`, `rollers`.
Наклейка для `brick` допускает до 12 символов: латиница, цифры, пробел и
`.&-`. `wall`: `outside` или `none`. `inlet`: `straight` или
`transfer_table`. Для нового оформления используйте исходный шаблон.
`scene.json` рядом с готовым ALP позволяет повторять прогоны с другой
интенсивностью без восстановления шаблонной трассы.

`video(tour=true)` для ЛР5 по умолчанию пишет развёрнутое окно Full HD на 2×
с плавной 2D-панорамой. Профиль `light` снижает разрешение и частоту захвата,
не меняя скорость модели. Если рядом есть `video-plan.json`, длительность
берётся из него, когда `seconds` не указан. Запуски закрываются вместе со своим
деревом процессов.

`bundle_lab5` собирает ZIP по структуре ЛР5. Передайте две модели и два
отдельных MP4, общий DOCX, PDF, CSV производительности и при необходимости
отдельную папку протоколов. В каждой папке задания видео называется
«Демонстрация.mp4».
