# Вид модели и видеодемонстрации

Для ЛР5 оформление задано файлом runtime/templates/presentation/lab-5.xml. Это обезличенные параметры исходного ALP: Frame 1000×600, две области просмотра, panelGroup, navigate, окно 3D и камера (50, 350, 200), углы 35° и −45°. Применяй общий профиль через restore_tabbed_views. Не заменяй его далёкой обзорной камерой, изменением масштаба панели, принудительным setCenter или слежением FollowCamera. Люди, рабочие места и погрузчики с водителями должны сохранять штатные изображения в 2D и 3D.

При запросе повторить конкретный образец сначала сравни исходный ALP и пример видео. Не объявляй соответствие по успешной компиляции: сравни границы окна, размер вкладок, исходную область 2D, угол и положение камеры. Изменение внешнего оформления не должно затрагивать физическую геометрию модели.

Для записи готовь отдельную копию проекта с реальным временем и нужной скоростью. В copy меняй только режим времени и выбранную вкладку. При записи 2D передавай three_d=false (CLI --no-three-d), при записи 3D — three_d=true (--three-d). MakeDefaultViewArea окна 3D должен соответствовать выбранному виду, чтобы он не перехватывал 2D-запуск. Не меняй Camera, FollowCamera, Frame или расположение вкладок ради записи.

Если требуется обзор всей длинной линии, это отдельный демонстрационный план; он не должен подменять стартовый вид ALP. Не называй обрезанный кадр полным обзором. Не заменяй живой запуск статичными картинками. Для сценария с несколькими планами используй video с shots и явно укажи монтаж отдельных запусков.

Для каждого задания 5.1 и 5.2 сохраняй рядом с ALP один файл «Демонстрация.mp4»: сначала 2D, затем 3D. В комплекте и ZIP должно быть ровно два MP4. Общий DOCX и PDF находятся в корне комплекта.

Сначала внеси все взаимосвязанные правки и проверь XML, ссылки и параметры исходного профиля. Затем проведи один итоговый цикл для обоих заданий. При обнаружении дефекта повторяй только не прошедшую проверку часть. Старые копии из run/model и прежние видео не выдавай за актуальный результат.

Для ЛР5 выдавай ровно ОДИН MP4 на задание: «Демонстрация.mp4» рядом с соответствующим ALP. Сначала покажи 2D, затем 3D с общим обзором всей линии и более близким ракурсом. По умолчанию общая длительность 20 секунд: 8 секунд 2D и 12 секунд 3D. Не выдавай отдельные файлы видов и старые обзорные ролики в комплекте или ZIP. При замене видео сначала создай и проверь финальный монтаж, затем очисти предыдущие MP4 и пересобери ZIP, проверив, что осталось ровно два видео. Можно использовать ранее проверенные записи той же актуальной модели через shots.source/start, чтобы не повторять запуски. Это монтаж реальных показов: не скрывай монтажные склейки и не выдавай статичные кадры за движение. assemble_clips нормализует разрешение, частоту кадров и пропорции перед объединением.
