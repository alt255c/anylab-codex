# Вид модели и видеодемонстрации

Для ЛР5 оформление задано файлом runtime/templates/presentation/lab-5.xml. Это обезличенные параметры исходного ALP: Frame 1000×600, две области просмотра, panelGroup, navigate, окно 3D и камера (50, 350, 200), углы 35° и −45°. Применяй общий профиль через restore_tabbed_views. Не заменяй его далёкой обзорной камерой, изменением масштаба панели, принудительным setCenter или слежением FollowCamera. Люди, рабочие места и погрузчики с водителями должны сохранять штатные изображения в 2D и 3D.

При запросе повторить конкретный образец сначала сравни исходный ALP и пример видео. Не объявляй соответствие по успешной компиляции: сравни границы окна, размер вкладок, исходную область 2D, угол и положение камеры. Изменение внешнего оформления не должно затрагивать физическую геометрию модели.

Для записи готовь отдельную копию проекта с реальным временем и нужной скоростью. В copy меняй только режим времени и выбранную вкладку. При записи 2D передавай three_d=false (CLI --no-three-d), при записи 3D — three_d=true (--three-d). MakeDefaultViewArea окна 3D должен соответствовать выбранному виду, чтобы он не перехватывал 2D-запуск. Не меняй Camera, FollowCamera, Frame или расположение вкладок ради записи.

Если требуется обзор всей длинной линии, это отдельный демонстрационный план; он не должен подменять стартовый вид ALP. Не называй обрезанный кадр полным обзором. Не заменяй живой запуск статичными картинками. Для сценария с несколькими планами используй video с shots и явно укажи монтаж отдельных запусков.

Для каждого задания 5.1 и 5.2 сохраняй рядом с ALP один файл «Демонстрация.mp4»: сначала 2D, затем 3D. В комплекте и ZIP должно быть ровно два MP4. Общий DOCX и PDF находятся в корне комплекта.

Сначала внеси все взаимосвязанные правки и проверь XML, ссылки и параметры исходного профиля. Затем проведи один итоговый цикл для обоих заданий. При обнаружении дефекта повторяй только не прошедшую проверку часть. Старые копии из run/model и прежние видео не выдавай за актуальный результат.

Для ЛР5 выдавай ровно ОДИН MP4 на задание: «Демонстрация.mp4» рядом с соответствующим ALP. Сначала покажи 2D, затем 3D с общим обзором всей линии и более близким ракурсом. По умолчанию общая длительность 20 секунд: 8 секунд 2D и 12 секунд 3D. Не выдавай отдельные файлы видов и старые обзорные ролики в комплекте или ZIP. При замене видео сначала создай и проверь финальный монтаж, затем очисти предыдущие MP4 и пересобери ZIP, проверив, что осталось ровно два видео. Для запроса движения камеры не используй старые записи: выбирай tour=true.

Для запроса «сначала 2D, потом 3D, подвигай камеру» используй video(tour=true), CLI `video --tour`: один непрерывный реальный запуск. Сначала 40% длительности 2D; далее камера плавно движется от загрузки через упаковку к выходу и заканчивает общим обзором. Это не склейка старых ракурсов. Camera и FollowCamera меняются только в отдельной демонстрационной копии ALP. Итоговая модель сохраняет исходный ракурс образца. Движение камеры задаётся через Camera3D.setPos, setRotationX, setRotationZ и update(), а не перестановкой параметров update(double,...). Приёмка: кадры до/после переключения, середины и конца, наличие всех участков линии, фактическое изменение положения камеры и движение грузов. В комплекте ровно два MP4, без старых видео.

Маршрут должен рассчитываться по реальному времени записи (System.nanoTime), а не по time()/speed: на нагруженной машине симуляция может замедлиться и не успеть показать общий вид. Последние две секунды — общий ракурс всей линии. Приёмка кадров обязательна; пустой 3D или отсутствие конца линии — ошибка, такой MP4 не включать в комплект.

Для 5.2 обязательно показывай погрузчики вместе с сидящими водителями в 2D и в движущемся 3D-проходе у складов. В Forklift должны сохраняться forkliftWithWorker, forklift и sittingWorker, DrawMode=SHAPE_DRAW_2D3D, а ресурс sittingworker.dae входить в комплект. В 5.1 погрузчики не добавляются ради видеодемонстрации: эта часть посвящена среднему участку.

В проходе камеры ЛР5 сохраняй угол исходника Игнатова: RotationX=35°, RotationZ=−45°. Меняй положение и расстояние, не поворачивай камеру к виду сверху. Для 20 секунд видео: 8 секунд 2D, затем 3 секунды неподвижного 3D у начала, 1.5 секунды плавного перехода, 3 секунды у выхода/погрузчиков, 1.5 секунды перехода и 3 секунды общего обзора. На каждой позиции задерживайся, чтобы зритель успел рассмотреть сцену.
