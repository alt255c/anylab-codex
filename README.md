# AnyLab Studio

**Лабораторные по AnyLogic через Codex и локальную мастерскую на Windows.**

Выберите лабораторную, заполните данные студента и получите один ZIP с моделями, отчётом и материалами проверки. Можно работать из чата Codex или через веб-интерфейс AnyLab Studio.

[Установка](#установка) · [Запуск](#запуск) · [Сборка комплекта](#сборка-комплекта) · [Что входит в ZIP](#что-входит-в-zip)

## Установка

Понадобятся **Windows**, **AnyLogic**, **Python 3.10+** с лаунчером `py` и **Codex CLI** в PATH. Для записи видео нужен активный сеанс рабочего стола.

В PowerShell проверьте вход в Codex и установите плагин с зависимостями:

```powershell
codex login status
py -3 -m pip install -r https://raw.githubusercontent.com/alt255c/anylab-codex/v0.6.1/plugins/anylab/runtime/requirements.txt
codex plugin marketplace add alt255c/anylab-codex
codex plugin add anylab@anylab-marketplace
```

Если CLI просит войти, выполните `codex login`. Если маркетплейс уже подключён, обновите его командой `codex plugin marketplace upgrade anylab-marketplace`, затем снова выполните `codex plugin add anylab@anylab-marketplace`.

## Запуск

**Из Codex.** Напишите «Открой AnyLab Studio» и перейдите по локальной ссылке из ответа. Команда плагина называется `studio_open`.

**Из исходников.** Откройте PowerShell в папке репозитория и выполните:

```powershell
py -3 -m pip install -r plugins/anylab/runtime/requirements.txt
py -3 plugins/anylab/runtime/studio_web.py --output "$PWD/Сборки AnyLab"
```

Если браузер не открылся автоматически, скопируйте адрес `http://127.0.0.1:…` из PowerShell.

## Сборка комплекта

| Лабораторная | Что можно выбрать |
| --- | --- |
| ЛР1–3 | Вариант и данные для отчёта. Кнопка **«Выполнить через Codex»** запускает подготовку моделей, проверку и оформление отчёта. |
| ЛР4 | Станция метро, учебная планировка, торговый центр для 4.2, оформление и скорость показа. |
| ЛР5 | Трасса конвейера, деталь, палитра коробок и оформление цеха. |
| ЛР6 | Оформление АЗС, цвета, зона отдыха, парковка и другие дополнения. |

Для ЛР4–6 нажмите **«3D-предпросмотр»**, чтобы посмотреть кадры с разных ракурсов, или **«Собрать комплект»**, чтобы запустить эксперименты и получить ZIP. Поле **«Пожелания к модели»** передаёт индивидуальную доработку в Codex.

**«Остановить сборку»** завершает процессы этой задачи. **«Продолжить сборку»** использует сохранённые этапы. Если Studio попросит выполнить доработку через чат, нажмите **«Скопировать запрос»**, вставьте его в Codex и после выполнения вернитесь к той же сборке.

Прогоны AnyLogic, запись видео и упаковка ZIP выполняются локально. Codex подключается для ЛР1–3, индивидуальных доработок и текста отчёта.

## Что входит в ZIP

- По одному проекту `.alp` и его ресурсам на задание.
- Общий отчёт в DOCX и PDF с результатами экспериментов.
- Для ЛР4–6 по одному MP4 на задание, кадры и 3D-ресурсы. В видео показаны общий план, блок-схема и движение модели в 3D.

Кодировщик FFmpeg берётся из системы или из зависимости `imageio-ffmpeg`. PDF экспортируется через Word, LibreOffice или ReportLab. Word и LibreOffice сохраняют вёрстку DOCX ближе к оригиналу.

Подробные требования к моделям, экспериментам и отчётам описаны в [инструкциях AnyLab](plugins/anylab/skills/anylab/SKILL.md).
