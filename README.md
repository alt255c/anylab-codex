# AnyLab для Codex

Плагин для локального Codex на Windows. Готовит лабораторные по AnyLogic по номеру варианта, запускает модели и собирает общий отчёт. Обезличенные ALP-шаблоны для ЛР1–ЛР6 и DOCX-каркасы отчётов для ЛР1–ЛР6 входят в установку. Для ЛР6 входят две самостоятельные модели АЗС: четыре колонки с контролем очереди и расширение с двумя кассами и возвращением водителя к своей машине. Штатные 3D-объекты берутся из установленной AnyLogic.

## Установка

Установите Codex CLI, Python 3.10 или новее с лаунчером `py` и AnyLogic. Выполните в PowerShell:

```powershell
py -3 -m pip install -r https://raw.githubusercontent.com/alt255c/anylab-codex/main/plugins/anylab/runtime/requirements.txt
codex plugin marketplace add alt255c/anylab-codex
codex plugin add anylab@anylab-marketplace
```

Для видео плагин найдёт системный FFmpeg или воспользуется кодировщиком из установленной зависимости `imageio-ffmpeg`. PDF можно экспортировать через Microsoft Word, LibreOffice или ReportLab. Word и LibreOffice подходят для сохранения вёрстки DOCX. ReportLab создаёт PDF с собственной вёрсткой.

## Пример запроса

> Используй AnyLab. Выполни ЛР4 целиком, вариант 6. Нужны отдельные модели по заданиям, общий DOCX (с снимками модели) и видео на 20 секунд. Также создай копию PDF. Студент: Иванов Иван Иванович; группа: Бxx-xxx

Для ЛР4 можно выбрать станцию метро и приложить её план. По умолчанию используется учебный вестибюль. Для ЛР5 и ЛР6 можно задать собственное дополнение к открытому примеру, например изменить маршрут подачи деталей или правило выбора очереди на АЗС.


## ЛР5 в версии 0.5.0

Для 5.1 и 5.2 сначала согласуйте две идеи внешнего вида. Опции каждого вызова
`conveyor_scenario` независимы. Укажите `full_line: true` для 5.2 и начните с
соответствующего шаблона. Поддерживаются `compact_straight`, `extended_offset`
и `smooth_s`. Детали: `blue_sleeve`, `orange_sleeve`, `silver_spool` или
`brick`. Дополнительные цвета, прямой вход и декор передаются в `scene`.

```json
{
  "theme": "retro_factory",
  "colors": {"ordinary": "#C59444", "fragile": "#842E42", "manual": "#203A65", "sheet": "#D9B785"},
  "label": "Workshop",
  "label_color": "#B92129",
  "label_angle": 41,
  "inlet": "straight",
  "wall": "outside",
  "sign": "КИРПИЧНЫЙ ЦЕХ"
}
```

Темы: `classic`, `retro_factory`, `smart_factory`, `sci_fi`. Допустимые
ключи `colors`: `ordinary`, `fragile`, `manual`, `tape`, `sheet`, `rollers`.
Наклейка для `brick` допускает до 12 символов: латиница, цифры, пробел и
`.&-`. `wall`: `outside` или `none`. `inlet`: `straight` или
`transfer_table`. Для нового оформления используйте исходный шаблон.
`scene.json` рядом с готовым ALP позволяет повторять прогоны с другой
интенсивностью без восстановления шаблонной трассы.

`video(tour=true)` для ЛР5 по умолчанию пишет развёрнутое окно Full HD на 2×
с плавной 2D-панорамой. Профиль `light` снижает разрешение и частоту захвата,
не меняя скорость модели. Если рядом есть `video-plan.json`, длительность
берётся из него, когда `seconds` не указан. Запуски закрываются вместе со своим
деревом процессов.

`bundle_lab5` собирает ZIP по структуре ЛР5. Передайте две модели и два
отдельных MP4, общий DOCX, PDF, CSV производительности и при необходимости
отдельную папку протоколов. В каждой папке задания видео называется
«Демонстрация.mp4».
